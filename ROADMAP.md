# Roadmap

Phase definitions and detailed plans live in [`docs/archive/plan/`](docs/archive/plan/).
This file is the **living** summary — update it as work starts or completes.

---

## Phase 0 — MVP ✅

Core recommendation engine, localStorage persistence, Today/Log/History UI.

Status: **Complete**

## Phase 1 — Beta & PWA 🔜

Integration tests, PWA installability, UX polish, Discord feedback entry point,
Lighthouse performance.

Status: **Not started**

## Phase 2 — Pro

Server-backed accounts (NextAuth + Drizzle + Postgres), unlimited history,
cross-device sync, JSON/CSV export, Apple Health import (iOS native).

Status: **Not started**

## Phase 3 — Commercial

Stripe subscriptions, Terms of Service / Privacy Policy (Thailand entity),
privacy-friendly analytics, Discord support with 2-day response window.

Status: **Not started**

## Phase 4 — Production Launch

Coolify VPS deployment (production + staging), TLS, CI/CD, Sentry error tracking,
uptime monitoring, rate limiting, public go-live checklist.

Status: **Not started**
